🤖 4-Stage Agent Pipeline

Junior → Senior → Architect → Tech-Leader. DSPy-powered agents review, refine, and decide on architecture proposals, producing ADR checkpoints with Merkle chain integrity.

🔐 Enterprise Auth

OAuth2 (Google + GitHub), JWT access/refresh tokens, multi-tenant RBAC (admin/user/readonly). Legacy API key support. PostgreSQL-backed.

🖥️ TUI + Web + Desktop

Rust TUI (ratatui) for power users. Leptos WASM Web Console for teams. Tauri Desktop app for cross-platform native experience.

☸️ Kubernetes Native

Production Helm chart: 3-10 replicas, HPA autoscaling, ingress TLS, rolling updates. Works with any Kubernetes cluster.

🔒 mTLS End-to-End

Mutual TLS between all control planes. Built-in PKI generator. rustls-native with zero OpenSSL dependency.

📡 Streaming + Real-Time

SSE streaming for agent output. NATS JetStream event bus. Prometheus metrics. OpenTelemetry tracing.
